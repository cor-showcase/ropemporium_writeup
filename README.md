# ROPEmporium Writeup
Hi! This is my writeup for the [ROPEmporium](https://ropemporium.com/). The wargame aims to teach about return oriented programming, and as such provides a series of challenges. Each challenge exponentially increases in difficulty due to the new concepts/techniques/challenges you have to learn to solve it. At the end, you would have event learnt ROP to such a level that you can defeat ASLR!

In this writeup I explain how to solve each challenge, then provide my exploit. You can run the exploit by pasting it into a  file called "exploit", dropping that into the folder provided by the challenge, then running:

> chmod +x ./exploit\
> ./exploit

I highly recommend doing these challenges for yourself, as they are very very fun. Especially fun if, like me, this was your first exposure to the concept!
